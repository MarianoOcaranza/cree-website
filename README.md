# Sitio web CREE - Centro de Recreación y Educación Especial


## Instrucciones
(es necesario tener instalado node)
- Clonar el repositorio localmente
- Ejecutar el comando npm install para instalar todas las dependencias necesarias
- Ejecutar el comando npm run dev
- Abrir el sitio en el navegador con localhost:5173 

Cada modificación que se haga produce un reload, así que pueden modificar código e ir viendo los cambios en tiempo real.

Dentro de la carpeta pages van a encontrar CDD.jsx, CFI.jsx, Escuela.jsx, Landing.jsx y NotFound.jsx. Estos son los componentes React principales que van a representar las secciones de nuestras páginas

Dentro de la carpeta components van a estar los componentes pequeños que componen a las pages (por ejemplo, el Header).
